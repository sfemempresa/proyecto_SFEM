Requerimientos para el funcionamiento del proyecto
---------------------------------------------------
Tener instaladas las siguientes aplicaciones:
- XAMPP Control Panel (indispesable)
- MySQL Workbench (indispensable)
- Visual Studio Code (no indispensable, pero es mas comoda para editar el codigo en general)
---------------------------------------------------------------------------------------------
Pasos para ejecutar el programa:
- Descargar la carpeta sfem del GitHUB
- Ir a la siguiente direccion en tu computador C:\xampp\htdocs
- Colocar la carpeta sfem en dicha direccion
- Abrir XAMPP Control Panel
- Iniciar los servicios de Apache y MySQL
- Apretar el boton ADMIN en la linea de MySQL
  (sera redirigido a phpMyAdmin)
- Verificar que esta parado sobre la base de datos hospital_clinicas
- Ir luego al apartado SQL en la barra de navegacion (parte de arriba) y pegar la tabla en el texto BD
- Luego darle al boton continuar  
- Luego en el buscador debe de pegar el siguiente enlace
  http://localhost/sfem/php/temporal.php
- Una vez creado el rol de admin, debe pegar este enlace
  http://localhost/sfem/php/index.php
- Ingrese con los siguiente datos
  - CI: 12345666
  - passw: Admin123
